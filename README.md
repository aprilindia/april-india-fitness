# April India Fitness website

A responsive, static website for GitHub Pages.

## Files
- `index.html` — page content and navigation
- `styles.css` — responsive styling and brand colours
- `script.js` — mobile navigation and current-year footer
- `assets/` — headshot, 1:1 coaching poster, transformation imagery and corporate brochure PDF

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `april-india-fitness`).
2. Upload **all files and folders inside this package** to the repository root. Keep `index.html` at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment.

No build tools or paid hosting are required. The contact buttons use email and social links; there is no server-side contact form.

## Before publishing
- Confirm that you have permission to publish all client photographs and testimonials online.
- Review the claims, qualifications and service descriptions for accuracy.
- The corporate brochure is included as a downloadable PDF.
- Consider adding a custom domain later if you have one.
