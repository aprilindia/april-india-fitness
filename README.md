# April McLean — Health, Wellness & Performance Website

This is a free, responsive static website designed around April's current career positioning:
Health & Wellness → Nutrition → Behaviour Change → Performance → Professional/Corporate Wellness.

## Files
- `index.html` — website
- `style.css` — styling
- `assets/april-headshot.png` — professional headshot
- `April-Coaching-Portfolio.pdf` — optional downloadable portfolio

## Publish for free
### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload all files in this folder.
4. In the repository, go to Settings → Pages.
5. Choose the main branch as the deployment source.
6. GitHub will give you a free `github.io` web address.

### Netlify
You can also create a free account and drag this folder into Netlify's deployment area. Netlify will provide a free web address.

## Before publishing
- Replace the temporary/placeholder social links if needed.
- Connect your preferred domain (`formephysique.online`) if you want to use it as the public address.
- If you want to publish identifiable client stories, obtain permission first. The case studies on this site are anonymised.
- Consider adding a formal privacy policy/contact form once the site starts collecting visitor information.
